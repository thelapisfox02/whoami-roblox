About

Roblox backend and systems programmer. Reusable modules, data layers, internal plugins and UI integration. Co-lead programmer on a 190M+ visit game. I also take general gameplay scripting.

What I work with

  • Luau
  • ModuleScript architecture
  • ProfileService and data layers
  • Roblox GUI library and core services
  • Studio plugins
  • Remote validation
  • Animation events
  • Networking
  • Tailscale / home server

UI work means integration and engineering, not visual design.

Numbers and analysis

I like turning spreadsheets of game data into decisions: economy balance, progression curves, drop rates, where players stall. An example is the bait-value model for Fish In A Pond.

My AI policy

  • If a job post says no AI, I use none.
  • If a post welcomes it, I use my own tooling and review everything I ship.
  • Every project in this portfolio says which parts I wrote by hand and which parts AI built. The two are never mixed in one line.
