Roll Gems for Money

Properties
RoleLolCo Games
AuthorshipAI-assisted
Key number1,447 visits

Roll for minerals, equip them on a plot, collect their coins, fuse them into new indexes and rebirth. It is a LolCo Games project with 1,447 visits and 4 up / 2 down votes.

AI wrote all the code, following detailed recipes written by me and another developer (stat formula, chunk economy, catalog model). Every system was verified and tested by humans in Studio.

How it works

  • One module, the coin ledger, is the only writer of the balance. Every credit or debit carries a transaction id, so a retried request applies once, and a reused id with a different amount is rejected.
  • Every stat uses one formula, (1 + sum of additive bonuses) × (1 + sum of multiplier bonuses), shared by upgrades and events. A buy request carries the level the client saw, so a double click charges once.
  • World events are deterministic. The schedule comes from the clock and a seeded roll, so every server agrees without talking to the others.
  • Fusion survives retries. The client sends the fusion count it expects and the server accepts only the next one, so a double click cannot spend inputs twice.
  • Drop odds run luck through a falloff curve and a per-tier cap, and a catalog validator rejects a rarity ladder that is not strictly rarer.
  • It runs the WiltedSuite services (Monetization, Inventory, Harvest) and saves through DataService on ProfileStore.

Third-party: DataService (leifstout), ProfileStore, QuickZone, Cmdr, InfiniteMath, TopbarPlus. Play on Roblox
