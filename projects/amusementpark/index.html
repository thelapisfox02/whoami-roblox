Fårup Sommerland

Properties
RoleSole lead programmer and co-developer, client commission
AuthorshipHandcrafted · AI-assisted
Key number351-line code sample

Fårup Sommerland is an amusement park experience, built on a client commission. It has a minigame framework, vehicles, collectibles and a roller coaster.

Systems

Written by me, without AI.

  • The limited-event collectibles are checked on the server for every claim, with per-source cooldowns, a reward grant that cannot duplicate, and an analytics funnel that shows where players drop off. Read the redacted code (351 lines). On GitHub.
  • UGC item purchases are driven by ConfigService, so the item list changes without publishing. It is cached, with fallbacks.
  • A minigame framework handles the queue, teleport and in-progress states. Race, golf, hotel and more are built on it.
  • For the UI, a window manager tweens open and close, fades the HUD and reads per-window positions from attributes. Windows are found by tag, so new ones need no wiring. A skin picker rebuilds from live ownership each time it opens, and a countdown ticks locally and re-syncs with the server every 30 seconds.

Code sample

Hand-written

Limited-event collectible service, 351 lines, strict Luau, server-authoritative. Below is the redeem path: a forged request is rejected because the server re-checks all five coins before it sets the flag.

LimitedEventCoinsServiceModuleScript · lines 254-283
-- True when all five slots hold a coin from an accepted way. Does not mutate anything
-- beyond Normalize's scrubbing -- this is the gate Redeem checks, not a state change.
function LimitedEventCoinsService.Verify(profile): boolean
	local coins = LimitedEventCoinsService.Normalize(profile)
	for i = 1, LimitedEventInfo.MaxCoins do
		if not isValidCoin(coins[i]) then
			return false
		end
	end

	return true
end

-- Marks the collection as redeemed. Server-authoritative: the client may ask, but the
-- five coins are re-checked here, so a forged request from a player who has not
-- collected them all is rejected.
function LimitedEventCoinsService.Redeem(profile): (boolean, string?)
	local data = profile:GetData()

	if data.LimitedEventCompleted == true then
		return false, "ALREADY_REDEEMED"
	end

	if not LimitedEventCoinsService.Verify(profile) then
		return false, "INCOMPLETE"
	end

	profile:SetBooleanValue("LimitedEventCompleted", true)
	return true
end

Roller coaster runtime

AI-assisted rewrite

A rewrite of the ride runtime for the Fårup Sommerland experience. It started on the open-source Hammerhead CFrame coaster kit by DaytonaShark. I wrote part of it myself. The old codebase was hard to navigate, so AI translated many of its layers and did much of the rewriting. It keeps the kit's physics model (gravity and friction constants), and nothing live references the kit any more.

  • Track built from segments and zones, station dispatch with stall recovery, e-stop and automatic mode.
  • Server-authoritative ride state with client-side visuals, and a diagnostics channel that reports the last error.

Not offered as a code sample: it is a port of an existing kit, partly AI-translated.
