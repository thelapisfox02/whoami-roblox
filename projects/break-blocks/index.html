Break Blocks for Money

Properties
RoleSolo
AuthorshipAI-made
Key number~8,050 lines of Luau

A test of what my curated AI tooling can produce in one day. It is a fresh game with almost no players, so it proves speed, not play quality or code style.

It was built with my curated AI tooling driving Roblox Studio over MCP, plus Python helper scripts that build the world and push scripts. It uses 16 AI-generated icons, Roblox free-library sounds and ProfileStore for saves.

The file timestamps in the project folder show files written between 05:13 and 23:57 on 11 Nov 2026, in ten separate hours (18 h 44 min elapsed). The first-party code is 28 Luau files, about 8,050 lines, 24 of them in strict Luau, with the economy maths and the ball simulation kept pure and shared between server and client.
