Modelling drop luck and bait value

AI-assisted analysis

Question: does each timed luck bait pay for itself? Method: rebuilt the live catch logic from the game's own data (a rarity ladder, eight mutations with exclusion rules, a weight roll), solved the expected value exactly, and cross-checked it with a 20,000-cast simulation. The two agree (1,522.6 vs 1,520.2 at luck 5.5; 39.0 vs 38.0 at luck 0.75).

  • Expected fish value per cast rises from 35 with no luck to 73, 233, 753 and 2,863 at luck 0.75, 2, 3.5 and 5.5.
  • Set against each bait's own time window (at least 3.75 s per cast), seven of fifteen baits cost more than a player can earn from them, even with every upgrade bought. The three top-luck baits return 5 to 13 cents per doubloon spent.
  • The older pricing script predated timed baits and referenced fields that no longer exist, so I replaced it with a model of the live code.

Case study · results and assumptions · model code

Outcome so far: no prices changed. Every bait also has a Robux product, so the doubloon price may be a deliberate sink; purchase analytics would settle which.
